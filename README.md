# Чат-бот для сайта efactoring.kz (ответы на общие вопросы про факторинг)

WordPress-плагин. Отвечает посетителям на общие вопросы про факторинг по заранее подготовленной таблице вопросов и ответов (CSV/XLSX), поддерживает русский и казахский языки, быстрые подсказки, передачу диалога менеджеру и статистику частых вопросов.

## Состав
- `efactoring-chatbot.php` — основной файл плагина.
- `includes/` — классы данных, статистики, AJAX, админки.
- `assets/` — стили и скрипт виджета.
- `data/sample-qa.csv` — пример таблицы.
- `demo/` — демонстрационная страница (без WordPress).
- `docs/INSTALL.md`, `docs/FORMAT.md` — инструкции.

## Установка
См. `docs/INSTALL.md`.

## Приёмка (ТЗ)
- Бот отвечает на 30 тестовых вопросов из набора без ошибок.
- На вопросы вне набора не придумывает ответы, предлагает связаться с менеджером.
- Диалог передаётся менеджеру (email/Telegram).
