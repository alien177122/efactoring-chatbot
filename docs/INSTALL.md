# Инструкция по установке виджета чат-бота

## Требования
- WordPress 5.0+
- PHP 7.4+
- Доступ администратора к сайту (устанавливает заказчик)

## Установка
1. Скачайте архив `efactoring-chatbot.zip`.
2. В админ-панели WordPress: **Плагины → Добавить новый → Загрузить плагин**.
3. Выберите архив и нажмите «Установить», затем «Активировать».
4. В меню появится пункт «Чат-бот». Откройте его.

## Настройка
1. Вкладка **Настройки**: укажите название, приветствия на RU и KK, цвет, email менеджера (обязательно). При необходимости — Telegram bot token и chat id.
2. Вкладка **База знаний**: загрузите файл CSV или XLSX с вопросами и ответами. Формат — см. `FORMAT.md`.
3. Сохраните. Виджет автоматически появится в правом нижнем углу сайта.

## Ручная вставка (опционально)
Используйте шорткод `[efactoring_chatbot]` в любом блоке/странице, если нужно встроить виджет в конкретное место.

## Обновление базы знаний
После изменения файла заказчик загружает новую версию во вкладке «База знаний» — участие исполнителя не требуется. Предыдущая версия заменяется.

## Статистика
Вкладка **Статистика** показывает частые вопросы и вопросы без ответа. Доступна выгрузка в CSV (агрегированная и полная) и очистка.

## Передача диалога менеджеру
Кнопка «Связаться с менеджером» отправляет имя, контакт, сообщение и историю диалога на email менеджера (и в Telegram, если настроен).
