Презентация продукта: Чат-бот для сайта efactoring.kz

Назначение

Виджет чат-бота для публичного WordPress-сайта efactoring.kz, отвечающий на типовые вопросы о факторинге (что такое уступка права требования, отличие от кредита, документы поставщика госзакупок, шаги финансирования). Источник знаний — таблица вопросов и ответов (CSV/XLSX), обновляемая заказчиком.

Соответствие требованиям ТЗ

  • Виджет для WordPress, подключается плагином или блоком кода.
  • Русский и казахский языки (интерфейс и ответы).
  • Быстрые подсказки частых вопросов.
  • Кнопка «Связаться с менеджером» — передача диалога на email/Telegram.
  • Статистика частых вопросов с выгрузкой CSV.
  • Бот отвечает только по переданному набору; на вопросы вне набора предлагает связаться с менеджером.
  • Не использует расчёты, тарифы и данные клиентов.
  • Доступ только к файлу (CSV/XLSX), без API, БД, платформы и исходного кода.

Архитектура

  • WordPress-плагин efactoring-chatbot (PHP 7.4+, WP 5.0+).
  • Источник знаний: файл qa.json, генерируемый из загруженного CSV/XLSX.
  • Поиск ответа на клиенте (нормализация, fuzzy matching) — без внешних сервисов.
  • Логирование и контакт — через встроенный admin-ajax.php WordPress.
  • Хранение статистики — таблица wp_efc_stats.

Установка (выполняет заказчик)

  1. Загрузить zip через «Плагины → Добавить новый → Загрузить».
  2. Активировать.
  3. В меню «Чат-бот» указать email менеджера, загрузить CSV/XLSX.
  4. Виджет автоматически появляется на сайте. Опционально шорткод [efactoring_chatbot].

Обновление базы знаний

Заказчик обновляет файл и загружает во вкладке «База знаний» — участие исполнителя не требуется.

Приёмка

  • 30 тестовых вопросов из набора — ответ без ошибок.
  • Вопросы вне набора не получают выдуманных ответов.
  • Диалог передаётся менеджеру (email/Telegram).

Демо

Локальная демонстрация: demo/index.html (без WordPress).
