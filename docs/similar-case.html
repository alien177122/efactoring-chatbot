Кейс: виджет чат-бота для сайта (FAQ, RU/KK)

Реализован лёгкий чат-бот для сайта с базой знаний из CSV/XLSX: поддержка двух языков, быстрые подсказки, передача диалога менеджеру, статистика частых вопросов. Использован тот же подход: ответы строго по набору, без LLM и расчётов.

Что было сделано

  • Парсер CSV/XLSX и нормализация вопросов.
  • Fuzzy-поиск по набору с порогом схожести.
  • Виджет с переключением языка и быстрыми вопросами.
  • Форма «Связаться с менеджером» с отправкой на email.
  • Статистика и экспорт CSV.

Результат

Снижение нагрузки на менеджеров, мгновенные ответы посетителям, возможность обновления базы без участия разработчика.
