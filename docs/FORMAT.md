# Формат таблицы вопросов и ответов

## Файл
- Форматы: CSV или XLSX.
- Кодировка CSV: UTF-8 (с BOM допустимо).
- Разделитель CSV: запятая или точка с запятой (определяется автоматически).
- Объём: 50–100 пар на старте, далее пополняется.

## Колонки (заголовки, регистр не важен)
1. `вопрос` (question) — текст вопроса.
2. `ответ на русском` (answer_ru / ответ на русском) — ответ на русском языке.
3. `ответ на казахском` (answer_kk / ответ на казахском) — ответ на казахском языке.
4. `категория` (category) — категория вопроса.

## Правила
- Первая строка — заголовки.
- Пустые строки пропускаются.
- Строки без вопроса пропускаются.
- Ответы пишутся на основе открытой информации о факторинге, без расчётов, тарифов и данных клиентов.
- Бот отвечает только по переданному набору; на вопросы вне набора предлагает связаться с менеджером.

## Пример (CSV)
```
вопрос;ответ на русском;ответ на казахском;категория
Что такое факторинг?;Факторинг — это...;Факторинг — бұл...;Общее
```
